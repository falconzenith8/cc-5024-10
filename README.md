# 古地图影像配准工具 (georect)

将扫描古地图通过**显式、平滑的非刚性变形**(二维薄板样条, TPS)配准到参考平面。
用户在扫描图与参考平面上标注若干对应地标, 程序拟合变形场并把原图重采样到目标网格。

设计原则:

- **不夸大精度**: 控制点拟合误差与未约束区域的不确定性分别呈现; 几个点吻合
  不代表整幅图具备精确地理定位。
- **可解释正则化**: 唯一的平滑参数 λ 直接惩罚弯曲能量, 含义明确。
- **退化检查**: 重复点、近共线、矛盾对应、病态条件数、折叠、非有限值
  都会给出诊断, 绝不输出含折叠或 NaN/Inf 坐标的图。
- **边界诚实**: 反向采样说明求逆方法与失败区域; 源图覆盖范围之外
  不凭空生成地图内容(输出透明无数据)。
- **不做四角透视**: 不使用单应(homography)/四角拖拽代替局部非刚性处理;
  仿射项只负责整体定向, 局部形变由 TPS 核逐项表达。

## 方法

### 变形模型

```
f(x) = c0 + C1·x + Σ_i w_i · U(|x - p_i|),   U(r) = r²·ln r
```

- 仿射项 `(c0, C1)`: 整体平移/旋转/缩放/错切;
- 核权重 `w_i`: 以地标为中心的局部非刚性修正, 随距离平滑衰减。

拟合目标: `min Σ|f(p_i)-q_i|² + λ·E_bend`, 其中弯曲能量 `E_bend = tr(WᵀKW)`。
`λ=0` 精确插值; `λ→∞` 退化为纯仿射。界面同时显示 E_bend 数值。

数值稳定性: 线性系统在归一化坐标(零均值、均方半径 1、无量纲核 ρ²lnρ)中求解,
可证明与用户坐标直接求解给出同一个样条(常数项被吸收进仿射项), 但条件数
不再随图像尺寸爆炸(演示数据从 1.7e15 降到 ~1e4)。导出的权重、仿射、λ 均在
用户坐标系下解释。

### 不确定性(与拟合误差分开呈现)

- **控制点拟合误差**: 每个地标的拟合残差(红色矢量)与 RMS/最大值;
- **留一交叉验证 (LOOCV)**: 逐点留出重拟合, 衡量"该地标若不存在会被预测成
  什么样", 是发现错误地标与估计预测误差尺度 σ̂ 的基础;
- **未约束区域不确定性**: TPS 等价于内在随机场克里金, 预测方差由系统矩阵给出
  `Var[f(x)] = -σ̂²·m(x)ᵀM⁻¹m(x)`, 控制点处为 0、离地标越远越大, 以热力图呈现;
- **凸包以外**: 属于外推, 以灰色遮罩单独标记为"未约束区域", 不与拟合误差混淆。

### 诊断

| 检查 | 含义 |
|---|---|
| 重复点 | 源/目标平面中距离过近的点对 |
| 矛盾对应 | 源点几乎重合、目标却明显不同(数据错误) |
| 近共线 | 控制点近似共线, 垂直方向变形不可辨识 |
| 条件数 | 归一化系统矩阵条件数, 过大说明几何布局接近退化 |
| LOOCV 标记 | 留一残差显著偏大(下半部 MAD 稳健准则, 抗多异常遮蔽) |
| 折叠 | 源域网格上 det J ≤ 0(相对主符号), 变形在该处翻折、不可逆 |
| 非有限 | 变形场任意位置出现 NaN/Inf |

### 反向采样(求逆方法与失败区域)

TPS 正映射没有解析逆。对每个输出像素的目标坐标 y, 用**阻尼牛顿法**解
`f(x) = y`: 初值取仿射逆, 单步位移受限(信赖域), 收敛判据默认 0.01 输出像素。
逐像素记录失败原因:

- `奇异`: |det J| 过小(多发生在折叠区);
- `未收敛`: 超过最大迭代次数;
- `非有限`: 迭代出现 NaN/Inf;
- `越界`: 收敛到的源坐标在源图之外 —— 不采样、不编造内容。

失败/越界像素在输出 RGBA 中 alpha=0, 统计与掩膜在界面中展示。

## 运行

```bash
pip install -r requirements.txt   # 或: pip install numpy flask pillow pytest
python3 server/app.py             # 打开 http://127.0.0.1:5000
```

界面流程:

1. **加载扫描图**(必须)与**参考图**(可选; 不加载则用虚拟网格);
2. 设置**参考平面范围**(世界坐标, y 向上; 加载参考图后默认为图像像素范围);
3. "添加地标"模式下: 先点左图(扫描图)地标位置, 再点右图对应点, 即成一对;
   "移动/选择"模式可拖动修正、双击或 Delete 删除; 每次增删改都会实际重算;
4. 调节 λ 观察变形网格、残差、不确定性的变化;
5. 叠加层: 不确定性热力图 / 凸包外区域 / 变形网格 / 残差矢量 / 折叠警告 /
   配准结果 / 求逆失败掩膜;
6. **重采样到参考网格**生成配准图; **导出变形参数**(JSON: 控制点、权重、仿射、
   λ、诊断摘要)与**导出配准图**(RGBA PNG, 无数据处透明)。

地标也可从 CSV(`sx,sy,tx,ty` 每行一对)或此前导出的参数 JSON 导入。

## 测试

```bash
python3 -m pytest tests/ -q        # 25 项测试
python3 scripts/make_demo_data.py  # 生成 demo/ 演示数据
```

测试覆盖:

- **已知平滑变形**: 由真值场生成扫描图, 比较恢复变形的坐标残差(最大 <3px)
  并确认无网格翻折;
- **局部纸张伸缩**: 紧凑强拉伸, 验证加密地标后残差显著下降;
- **错误地标**: 注入错位/互换对应, 验证 LOOCV 标记与折叠检测触发;
- **重复点/近共线/奇异系统**: 诊断正确报告, 不抛出未处理异常;
- **反向采样**: 与参考图数值比较; 边界外像素必须透明无数据(不编造);
  折叠变形中失败像素被显式统计; 输出绝不含非有限值;
- **API**: 上传/拟合/重采样端到端。

演示数据 (`demo/`): `reference.png`(现代参考图)、`scanned.png`(经已知真值场
扭曲的"古地图", 含两处平滑鼓包与一处局部纸张伸缩)、`landmarks.csv`(36 对正确
地标)、`landmarks_with_errors.csv`(含 1 个错位与 1 对互换地标, 用于演示诊断)。
参考平面范围设为 `xmin=0 ymin=0 xmax=1000 ymax=800`。

## 局限性(如实说明)

- 地标少或分布不均时, 远离地标区域的变形**不可知**; 不确定性热力图给出的是
  模型内估计, 不是精度保证;
- λ 的合适取值与目标坐标单位有关, 请结合 LOOCV 残差与变形网格目视选择;
- 强局部伸缩需要局部加密地标才能恢复;
- 本工具不做色彩校正与图像增强。
